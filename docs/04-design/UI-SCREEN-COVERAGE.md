## 3. Critical Design & Workflow Gaps

### Gap 1: Zero Delivery Partner Screens in Stitch

- **Severity**: High.
- **Finding**: The Stitch canvas has complete screens for Customer, Merchant, and Admin, but completely omitted the fourth core user type: **Delivery Partner**.
- **Impact**: Although `DeliveryPartnerInboxPage.tsx` exists in `apps/web` as a functional wireframe, there is no Stitch visual guide for the mobile dispatch workflow (order offer card, pickup arrival button, customer PIN verification, and COD collection confirmation).

### Gap 2: Incomplete Customer Pre-Order Journey in `apps/web`

- **Severity**: High.
- **Finding**: `apps/web` currently jumps directly from `/login` to `/orders` (order history). A customer cannot browse stores in Badarpur, view catalogues, or add products to cart and checkout.
- **Required Implementation**: Bring the Stitch Marketplace Home (`#17`/`#2`), Store Catalogue (`#11`/`#33`), and Cart & Checkout (`#21`/`#29`) into `apps/web`.

### Gap 3: Multi-Step Merchant Onboarding Pipeline Missing in Frontend

- **Severity**: High.
- **Finding**: BC-006 built database models and backend validation for FSSAI licenses, Trade Licenses, GSTIN, and Bank accounts. Stitch designed 6 comprehensive screens covering this exact 3-step pipeline (`#6`, `#8`, `#20`, `#34`, `#35`, `#36`), but the frontend has zero onboarding pages.

### Gap 4: Missing Shared States (Loading, Empty, Offline, Success)

- **Severity**: Medium.
- **Finding**: While Stitch designed the OTP Expired/Error state (`#31`, `#37`), the following states need standardization:
    - Empty Cart drawer.
    - Store Closed / Outside Delivery Hours banner.
    - No Stores Found in Service Zone.
    - Network Offline alert with local retry button.

## 4. Prioritized Implementation Roadmap

1. **Phase 1: Design System Foundation (`apps/web`)**:
    - Establish styled-components theme matching Stitch design tokens (`Plus Jakarta Sans`, Coral `#FF5733`, Forest `#006E2D`, Surface `#FBF8FF`).
    - Implement base atomic components: Buttons (Coral pill CTA, stepper pill), Cards (Product, Store, Badge), and Badarpur header pill.
2. **Phase 2: Customer Core Journey**:
    - Route `/`: Dropzo Marketplace Home (`#17`/`#2`).
    - Route `/stores/:storeId`: Store Catalogue (`#11`/`#33`).
